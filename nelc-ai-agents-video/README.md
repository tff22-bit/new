# فيديو تعليمي متحرك: معايير وكلاء الذكاء الاصطناعي في التعليم والتدريب

مشروع Remotion (React + TypeScript) يحوّل وثيقة المركز الوطني للتعليم الإلكتروني (الإصدار 1.0، أكتوبر 2026م) إلى فيديو شرح متحرك بالعربية مع سرد صوتي متزامن.

- 22 مشهدًا · 1920×1080 · 30 إطارًا/ث · H.264 + AAC
- السرد هو الذي يحدد التوقيت: كل جملة ملف صوتي مستقل، ومدة المشهد = مجموع مدد ملفاته الفعلية + وقفات.
- الحركة مربوطة بعبارات من السرد (`c(رقم المقطع، "عبارة")`)، وتُستخدم علامات توقيت الكلمات من مزوّد الصوت عند توافرها.

## البنية
| المسار | المحتوى |
|---|---|
| `src/data/narration.json` | المصدر الموحد للنص: المشاهد والمقاطع وصفحات المصدر |
| `src/data/timing.json` | مُولَّد — مدد المقاطع الفعلية (أو تقديرية قبل توليد الصوت) |
| `src/timeline.ts` | تحويل المدد إلى جدول زمني بالإطارات |
| `src/components/` | مكونات قابلة لإعادة الاستخدام: `Loop` (دورة عمل)، `Conn`/`FlowDot` (روابط تُرسم ونقاط تدفق)، `AgentCore`، `StepBox`، `Card`، `Chip`، `Takeaway`، `SceneShell` (العنوان، الانتقالات، الصوت، المصدر، خريطة الأبعاد) |
| `src/scenes/S01…S22` | مشهد لكل فكرة، ولكل منها استعارة بصرية خاصة |
| `scripts/tts.py` | توليد السرد (Polly / Azure / ElevenLabs / Google) من متغيرات البيئة |
| `docs/` | تحليل المحتوى، نص السرد، لوحة القصة، جدول التتبع |

## التشغيل
```bash
npm install
python3 -m venv .venv && .venv/bin/pip install boto3   # أو حزمة المزوّد المختار
.venv/bin/python scripts/tts.py --provider polly --voice Zayd   # أو azure --voice ar-SA-HamedNeural
npm run timing        # تحديث المدد من ملفات الصوت
node scripts/build-docs.mjs   # تحديث لوحة القصة بالمدد الفعلية
npm run studio        # معاينة تفاعلية
npm run render        # يرفض التصيير إن كان أي مقطع بلا صوت → out/ai-agents-standards.mp4
```
فحوص: `npm run typecheck` · `node scripts/check-cues.mjs` (كل عبارة ربط موجودة في السرد) · `node scripts/stills.mjs <dir>` (صور مراجعة).
